# DoubtfulTurnip Kasm Workspaces Registry

## Add this registry to your Kasm instance

1. In Kasm Workspaces go to **Admin → Workspaces → Workspaces Registry**
2. Click **Add new**
3. Paste the registry URL:

   ```
   https://<your-username>.github.io/doubtfulturnip-kasm-registry/
   ```
4. Click **Add Registry**

---

## Available Workspaces

### Bloodhound

Graph-based Active Directory analysis. Maps users, sessions, and privileges to identify attack paths and escalation opportunities.

### Epaneul

Web endpoint discovery using tools like `ffuf` and `gobuster` to uncover hidden directories, files, and parameters.

### LogonTracer

Visualizes Windows Security Event logs to track logon behavior and lateral movement. Useful for forensics and intrusion analysis.

### Slasher

Content discovery and brute-force tooling (e.g., `wfuzz`, `dirsearch`, `hydra`) to find hidden content and weak credentials.

### TruffleHog

Scans for high-entropy secrets and credential patterns in local filesystems or repositories. Supports 800+ secret types.

### Web-Check

A web security scanning suite including `OWASP ZAP`, `wpscan`, and `Nikto`. Automates detection of known vulnerabilities and misconfigurations.
